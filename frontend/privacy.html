AgriSetu Privacy Policy

How we protect farmers and labourers' personal information

1. Contact Number Privacy (Zero Public Disclosure)

To prevent spam, harassment, and unauthorized wage marketing, AgriSetu enforces a strict Contact Privacy standard:

  • Mobile numbers are NEVER displayed on public job listings or search results.
  • A labourer's phone number is hidden from the farmer until the farmer formally accepts their application.
  • A farmer's phone number is masked until an applicant is accepted or has an active assignment.
  • Once an assignment is confirmed, both parties receive authorized access to phone contact buttons (tel: links) for direct coordination.

2. Password Security and Encryption

All user passwords are encrypted using industry-standard BCrypt hashing with salt. Plaintext passwords are never stored in SQL Server, never logged in server consoles, and never exposed in any API response.

3. Language Preference & Data Rights

Users can modify their profile details, language preference (Telugu, Hindi, English), and notification settings at any time from their Profile page. For account deactivation or dispute moderation, complaints can be submitted directly via the built-in reporting system.
